# IE4060 – Autonomous Navigation of TurtleBot3 Burger

## Project Overview

This project focuses on developing an autonomous navigation system for the TurtleBot3 Burger robot in a custom maze environment using Gazebo and ROS 2 Jazzy.

## Project Objectives

- Create a custom maze environment in Gazebo.
- Map the environment using SLAM.
- Implement autonomous navigation using ROS 2 Nav2.
- Allow users to select a destination on the map.
- Implement and evaluate a Deep Q-learning approach.
- Evaluate navigation performance using travel time, path length, and obstacle avoidance.

## Technologies Used

- Ubuntu 24.04
- ROS 2 Jazzy
- Gazebo
- TurtleBot3 Burger
- SLAM
- Nav2
- Python

## Repository Structure

The repository will contain the Gazebo maze world, ROS 2 packages, launch files, navigation configuration, machine-learning implementation, screenshots, and project report.
